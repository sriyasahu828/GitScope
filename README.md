# 🚀 GitScope

GitScope is a modern GitHub Analytics Dashboard built with React and the GitHub REST API. It allows users to search any GitHub profile and instantly view developer insights, repository statistics, language usage, followers, and more through an interactive and visually appealing interface.

---

## ✨ Features

- 🔍 Search any GitHub username
- 👤 View developer profile details
- 📊 GitHub analytics dashboard
- ⭐ Total repository stars count
- 📦 Public repositories overview
- 👥 Followers & following statistics
- 💻 Programming language analysis
- 🚀 Repository explorer with direct links
- 🎨 Modern responsive UI
- ⚡ Real-time data using GitHub API

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/GitScope.git
```

Navigate into the project:

```bash
cd GitScope
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 🚀 Deployment

This project is deployed using Vercel.

Build the project:

```bash
npm run build
```

Deploy:

```bash
vercel
```

or connect the GitHub repository directly to Vercel.
